# PostoBot

PostoBot — бот обращений для «Образовательного квартала 1409» в мессенджере MAX.
Пользователь может оставить **заявку** или **предложение**, посмотреть свои заявки и архив.
Вместе с ботом идёт **веб-панель** (`https://postobot.su/apps`), где всё это же можно делать в удобном интерфейсе.

Ниже — простая пошаговая инструкция по установке на сервер.
Она рассчитана на людей, которые раньше не настраивали серверы, поэтому идём медленно и по шагам.

---

## Что понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Сервер (VDS) | На нём будет «жить» код бота и панели | Любой хостинг VDS, например Timeweb, reg.ru, Hetzner. Хватит самого дешёвого тарифа (1 ядро, 1–2 ГБ памяти), система — **Ubuntu 22.04 или 24.04** |
| Домен `postobot.su` | Его откроют пользователи, чтобы попасть в панель | Купить у любого регистратора доменов (например, reg.ru) |
| Токен бота (`MAX_BOT`) | Пароль бота, по которому код подключается к MAX | На платформе MAX: `business.max.ru` → там создаётся бот |
| Компьютер + доступ по SSH | Чтобы заходить на сервер и запускать команды | Пароль или SSH-ключ к серверу вам выдаёт хостинг |

> Если часть слов непонятна — не страшно. Дальше каждая кнопка расписана по шагам.

## Шаг 1. Домен → сервер (запись A)

В панели регистратора доменов найдите раздел **DNS / Редактировать DNS-записи** и:

1. Уберите все старые записи типа `A`, `AAAA`, `CNAME`.
2. Добавьте **одну** запись типа **A**:
   - Имя (Host): `@` (или оставьте пустым / `postobot.su`)
   - Значение (Target / Value): **IP-адрес вашего сервера**
   - TTL: оставьте как есть

3. Сохраните.

Изменения распространяются не мгновенно — может пройти до нескольких часов. Переходим к серверу, они ещё успеют «дойти».

---

## Шаг 2. Заходим на сервер (SSH)

Откройте **терминал**:

- **Mac**: приложение «Терминал».
- **Windows**: приложение PowerShell или PuTTY.

Команда подключения (вместо `123.123.123.123` вставьте IP сервера):

```bash
ssh root@123.123.123.123
```

- Спросит пароль — введите пароль от сервера (буквы при вводе не видны — так и должно быть).
- Перед этим может появиться вопрос про «fingerprint» — ответьте `yes`.

Вы «внутри» сервера. **Все следующие команды набираются в этом же окне.**

Проверим, что у вас Ubuntu:

```bash
lsb_release -d
```

Должно быть что-то вроде `Ubuntu 22.04.*` или `Ubuntu 24.04.*`. Если другая система — лучше начать с Ubuntu.

---

## Шаг 3. Загружаем проект на сервер

Нужно положить папку проекта **c вашего компьютера** на сервер. Удобнее всего это сделать **у себя на компьютере** в новом терминале (не в окне SSH):

```bash
# найдите путь до папки проекта и вместо /путь/до/папки подставьте его,
# а вместо 123.123.123.123 — IP сервера
scp -r /путь/до/папки root@123.123.123.123:/root/postobot
```

Например, если папка проекта лежит на Mac как `~/postobot_max_python`:

```bash
scp -r ~/postobot_max_python root@123.123.123.123:/root/postobot
```

> Нет `scp` или неудобно? Любым SFTP-клиентом (FileZilla и т.п.) закиньте папку проекта в `/root/postobot` — сработает так же.

Теперь вернитесь в окно SSH и проверьте, что всё на месте:

```bash
ls /root/postobot
```

Вы должны увидеть файлы `bot.py`, `config.py`, папку `html` и другие.

## Шаг 4. Вписываем токен бота (.env)

Откройте файл настроек:

```bash
nano /root/postobot/.env
```

Приведите его к такому виду (текст до `=` меняете на свой):

```dotenv
MAX_BOT=сюда-вставьте-токен-бота
ADMIN_ID=
```

- **MAX_BOT** — токен бота. Как получить: `business.max.ru` → ваш профиль организации → бот → поле «Токен». Нажмите «Скопировать» и вставьте *после* `=`.
- **ADMIN_ID** — пока оставьте пустым. Заполним на шаге 6.

Как сохранить в редакторе `nano`:
1. `Ctrl + O` → `Enter` (сохранить)
2. `Ctrl + X` (выйти)

---

## Шаг 5. Запускаем установку

Всё самое сложное сделает скрипт: установит Python и нужные программы, настроит веб-панель, включит бота и выпустит бесплатный сертификат безопасности (HTTPS).

```bash
cd /root/postobot
sudo bash html/deploy_vds.sh
```

Установка займёт несколько минут (появятся информирующие строки `[deploy]` и `[warn]`). В конце вы увидите:

```
=== Готово ===
Панель: https://postobot.su/apps
```

Теперь можно открыть в браузере **`https://postobot.su/apps`** — откроется панель.

> Если в конце вместо «SSL выпущен» появилось `[warn]` про сертификат — значит домен ещё не «доехал» до сервера (шаг 1). Подождите и через час выполните ещё раз:
> ```bash
> sudo certbot --nginx -d postobot.su --redirect
> ```

---

## Шаг 6. Узнаём свой ID и включаем админ-команды

Один раз заполним `ADMIN_ID`, чтобы у вас (как у администратора) работали команды `/all`, `/archive`, `/restore`.

1. Откройте бота в мессенджере MAX и отправьте ему команду:

   ```
   /id
   ```

2. Бот ответит примерно так:

   ```
   Ваш ID: 234631527
   ```

3. Запомните это число и снова откройте настройки:

   ```bash
   nano /root/postobot/.env
   ```

   Впишите:

   ```dotenv
   ADMIN_ID=234631527
   ```

   Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`).

4. Перезапустите бота:

   ```bash
   sudo systemctl restart postobot-bot
   ```

---

## Шаг 7. Подключаем панель к кнопке в боте

В меню бота есть кнопка «🖥 Панель обращений». Она открывает панель кнопкой в чате. Чтобы она работала, привяжите мини-приложение к боту на платформе MAX (`business.max.ru` → бот → мини-приложение), указав адрес:

```
https://postobot.su
```

Инструкцию MAX смотрите здесь: https://dev.max.ru/docs/webapps/introduction

## Полезные команды

Выполняйте их в окне SSH:

| Что нужно | Команда |
|---|---|
| Посмотреть, работают ли службы | `systemctl status postobot-web postobot-bot` |
| Живые логи бота | `sudo journalctl -u postobot-bot -f` |
| Живые логи панели | `sudo journalctl -u postobot-web -f` |
| Перезапустить бота | `sudo systemctl restart postobot-bot` |
| Перезапустить панель | `sudo systemctl restart postobot-web` |
| Обновить код после изменений | сложить новые файлы на сервер и ещё раз: `sudo bash /root/postobot/html/deploy_vds.sh` |

## Если что-то не работает

**Панель открывается только по `http://`, без `https://`**
Проверьте, что домен смотрит на сервер, затем выполните:
```bash
sudo certbot --nginx -d postobot.su --redirect
```

**Бот вообще не отвечает**
Проверьте токен: в `.env` после `MAX_BOT=` должен стоять ваш токен (шаг 4). Посмотрите логи:
```bash
sudo journalctl -u postobot-bot -e
```
Если там ошибка про `token` или `401` — токен неправильный.

**Страница не открывается совсем**
- Проверьте, что домен указан в DNS (шаг 1) и прошло время на распространение.
- Убедитесь, что файрвол сервера открывает порты 80 и 443:
```bash
sudo ufw allow 22/tcp && sudo ufw allow 80/tcp && sudo ufw allow 443/tcp
```

**Пользователи нажимают «Панель обращений», но ничего не открывается**
Не подключено мини-приложение к боту на `business.max.ru` — см. шаг 7.

## Структура проекта (для тех, кто хочет разобраться)

| Файл / папка | Что это |
|---|---|
| `bot.py` | Основной код бота (обращения, меню, команды) |
| `config.py` | Читает настройки из `.env` |
| `html/web_server.py` | Веб-панель (Flask) |
| `html/templates/apps.html` | Интерфейс панели |
| `html/deploy_vds.sh` | Скрипт установки на сервер |
| `requirements.txt` | Список библиотек Python |
| `data/requests.json` | База обращений (сохраняется автоматически) |

Данные — в файле `data/requests.json`. Перед обновлением кода советуем делать его копию.
